# Shooting-game
 A game that I've created ( btw this is my first repository.)
 Creator: Harshit Singh Negi
 Features included in the project:



• Player registration system

• Mouse controlled rocket launcher

• Automatic missile firing system

• Animated missile flame effects

• Dynamic star spawning and movement

• Real time collision detection

• Score tracking system

• 3 lives (heart based health system)

• Game over screen

• Persistent leaderboard using LocalStorage

• Responsive full screen gameplay

• Dynamic difficulty balancing through speed and spawn rate adjustments
